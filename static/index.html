SocialLab calcula satisfacción modelada con datos ficticios. La afinidad de una persona hacia otra es un promedio ponderado entre los rasgos observados y sus valores ideales. El backend enumera todas las asignaciones y prueba cada posible cambio unilateral para determinar si existe equilibrio de Nash.
